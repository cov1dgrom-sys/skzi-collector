# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-14

Первый выпуск модуля сбора данных о СКЗИ — кейс №03 ФГУП «ГРЧЦ», Всероссийский хакатон связи 2026, команда Red Flag.

### Состав выпуска

| Файл | Что это |
|---|---|
| `SkziControlPanel-Setup-1.0.0.exe` | Установщик панели управления для текущего пользователя (без прав администратора) |
| `SkziAgent-Setup-1.0.0.exe` | Установщик агента на ПК: служба Windows; тихий режим `/Q` для GPO и SCCM |
| `SkziModule-1.0.0-portable.zip` | Оба `.exe` без установки, примеры конфигураций, SQL-скрипт, документация |
| `SHA256SUMS.txt` | Контрольные суммы |

Требования: Windows 10+, .NET Framework 4.5+ (встроен в Windows 10/11), Microsoft SQL Server любого выпуска (Express, Developer, Standard, LocalDB).

### Возможности

- **Панель управления** (`SkziControlPanel.exe`): список ПК, импорт из файла, поиск агентов в диапазоне адресов, параллельное сканирование, результаты по каждому ПК, таблица БД с поиском и фильтрами, экспорт в CSV, установка и удаление агентов по сети, настройки, журнал.
- **Агент** (`SkziAgent.exe`): служба Windows без окон с автозапуском и перезапуском при сбое; скрыта от обычных пользователей дескриптором безопасности, администратор сохраняет полный контроль. Запасной режим `--background` без прав администратора.
- **Что собирается**: хранилища «Личное» всех пользователей (в том числе не вошедших) и компьютера; ключевые контейнеры КриптоПро (реестр, флешки, токены) через CryptoAPI без PIN; файлы в указанных папках — DER, PEM, Base64, PKCS#7, PKCS#12 с паролем оператора; версия КриптоПро CSP, серийный номер и срок лицензии на ПК.
- **Разбор сертификата**: серийный номер, владелец (ФИО), удостоверяющий центр, ИНН, СНИЛС, ОГРН, срок действия, алгоритм; встроенная лицензия КриптоПро (OID 1.2.643.2.2.49.2) и её версия.
- **MSSQL**: база и таблицы создаются автоматически, существующая таблица дополняется столбцами; запись без дублей по серийному номеру; дата внесения сохраняется, дата обновления растёт; пропавшие сертификаты помечаются, вернувшиеся — снимается отметка; таблица мест «сертификат — ПК — источник».
- **Режимы**: через агент (TCP 50555, HMAC-SHA256), без агента (`\\ПК\C$` и удалённый реестр), «Этот ПК», по расписанию (`--scan-all`).
- **Журнал**: формат `дд.ММ.гг чч:мм:сс.мсс - [УРОВЕНЬ] текст`, все исключения со стеком, ротация по суткам и размеру.
- **Безопасность**: панель запускается только от имени администратора; подпись запросов и ответов, одноразовое число, ограничение адресов панели, пароли под DPAPI, параметризованный SQL, закрытые ключи не читаются, обмен только внутри ЛВС.
- **Настройка без перекомпиляции**: порт агентов, папки, расширения, параметры БД и журнала — в `agent.config.xml` и `panel.config.xml`.
- **Сборка без Visual Studio** (`build.cmd`), 28 автотестов (3 из них — MSSQL), выпуск релиза одной командой (`release.cmd`).

### Известные ограничения

- Чтение контейнеров КриптоПро и срок лицензии CSP проверены автотестами без установленного КриптоПро CSP; на ПК с CSP — при проверке на стенде.
- Установка службы и её скрытие от пользователей проверены кодом и тестом параметров; на ПК с правами администратора — при проверке на стенде.
- Служба от «Системы» не видит контейнеры КриптоПро в реестре других пользователей (`HKCU` чужих профилей); контейнеры компьютера, флешки и токены видит.
- Установщики не подписаны цифровой подписью: SmartScreen может попросить подтверждение.
