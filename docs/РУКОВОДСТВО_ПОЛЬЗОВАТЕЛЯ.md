# Руководство пользователя

Для того, кто собирает сведения о СКЗИ: запускает сканирование ПК сети и работает с результатами в панели управления `SkziControlPanel.exe`.

Как установить программу и агенты — в [УСТАНОВКА_И_НАСТРОЙКА.md](УСТАНОВКА_И_НАСТРОЙКА.md).

Панель запускается только от имени администратора: при открытии Windows запросит подтверждение прав (UAC). Это защита от запуска рядовым сотрудником.

---

## Что делает программа

Панель опрашивает компьютеры локальной сети. С каждого ПК она получает:

- **личные сертификаты** — из хранилищ «Личное» всех пользователей и компьютера, из ключевых контейнеров КриптоПро (реестр, флешки, токены) и из файлов в папках, которые вы укажете;
- **сведения о КриптоПро CSP** — установлен ли он, какая версия, серийный номер лицензии (замаскирован) и срок её действия.

Из каждого сертификата извлекаются серийный номер, владелец, удостоверяющий центр, срок действия и встроенная лицензия КриптоПро. Результат записывается в таблицу MSSQL: одна строка на сертификат, без дублей. Сертификаты, которые пропали с ПК, помечаются.

---

## Окно панели

Окно состоит из четырёх вкладок. Внизу строка состояния: ход сканирования и текущее подключение к БД.

| Вкладка | Для чего |
|---|---|
| **Сканирование ПК** | Список ПК, запуск сканирования, результаты по каждому ПК |
| **Сертификаты в БД** | Таблица из MSSQL: поиск, фильтры, экспорт в CSV |
| **Журнал** | Журнал работы панели в реальном времени |
| **Настройки** | БД, агенты, папки для поиска, журнал |

## Сканирование

### 1. Указать, где искать файлы сертификатов

Кнопка **«Папки для поиска…»** в строке «Где искать». Пути пишутся так, как они выглядят на сканируемом ПК (`C:\Certs`). Поддерживаются:

- маски: `C:\Users\*\Desktop` — рабочие столы всех пользователей;
- переменные окружения: `%USERPROFILE%\Documents` (только на этом ПК и в агенте);
- флажок «С подпапками» у каждой папки.

Хранилища Windows и контейнеры КриптоПро проверяются всегда, независимо от папок. Отключить их можно в «Настройках».

### 2. Составить список ПК

Панель инструментов «Список ПК»:

| Кнопка | Что делает |
|---|---|
| **+ Добавить ПК** | Ввести имена или IP-адреса, по одному в строке |
| **Импорт из файла…** | Загрузить список из текстового файла |
| **Найти агенты в сети…** | Проверить диапазон адресов (`192.168.1.1-254`, `10.0.0.0/24`, несколько — через запятую) и добавить ПК, где отвечает агент |
| **Удалить** | Убрать выделенные ПК из списка (или клавиша Delete) |
| **Агент на ПК ▾** | Проверить связь с агентом, установить или обновить агент, удалить агент, сохранить `agent.config.xml` для ручной установки |

Список ПК сохраняется в конфигурации панели.

### 3. Выбрать способ и запустить

| Способ | Когда использовать |
|---|---|
| **Через агент (TCP)** — рекомендуется | На ПК установлен агент. Видны хранилища всех пользователей, контейнеры КриптоПро, срок лицензии CSP |
| **Без агента (\\\\ПК\\C$ + удалённый реестр)** | Агента нет, но у вас есть права администратора на ПК. Контейнеры КриптоПро и срок лицензии так не прочитать |
| Кнопка **«Этот ПК»** | Просканировать компьютер, на котором открыта панель |

Кнопки **«▶ Сканировать выбранные»** и **«▶▶ Сканировать все»** запускают сканирование. ПК опрашиваются параллельно (по умолчанию до 8 одновременно). **«■ Остановить»** прерывает сканирование.

### 4. Смотреть результат

Таблица ПК показывает по каждому компьютеру: статус, версию КриптоПро CSP, лицензию CSP на ПК, число сертификатов и сертификатов с лицензией, итог записи в БД, время сканирования и сообщение.

Выберите ПК в таблице, и внизу откроются три вкладки:

- **Сертификаты** — найденные сертификаты: серийный номер, владелец, организация, УЦ, срок, лицензия КриптоПро и её версия, есть ли закрытый ключ, где найден. **Истёкшие подсвечены красным.**
- **Сведения о ПК и КриптоПро** — версия CSP, серийный номер и срок лицензии, что и как проверялось.
- **Предупреждения** — недоступные папки, повреждённые файлы, `.p12` без пароля и т. п. Число предупреждений видно в названии вкладки. Предупреждения не останавливают сканирование.

Если в «Настройках» включено «Записывать результаты в БД сразу после сканирования», результаты попадут в MSSQL автоматически.

## Сертификаты в БД

Вкладка показывает таблицу `dbo.SkziCertificates`.

| Элемент | Что делает |
|---|---|
| **Обновить** | Перечитать таблицу из БД |
| **Поиск** + **Найти** / **Сбросить** | Поиск по части серийного номера, владельца, УЦ, имени ПК, ИНН, организации или отпечатка |
| Список **«Все сертификаты ▾»** | Все / Найденные / Пропавшие / Истёкшие |
| **Экспорт в CSV…** | Сохранить показанные строки; файл открывается в Excel |
| **Создать / проверить таблицу** | Создать БД и таблицу, если их нет; добавить недостающие столбцы |

Как читать строки:

- **красная** строка — сертификат истёк;
- **серая курсивом** — сертификат пропал: раньше он был найден, а при последнем сканировании тех же мест его там нет;
- **двойной щелчок** по строке — на каких ПК и где именно (файл, хранилище, контейнер) найден сертификат, с датами первого и последнего обнаружения.

Под таблицей — итоги: сколько всего, со встроенной лицензией, истёкших, пропавших.

**Повторное сканирование не создаёт дублей.** Строка с тем же серийным номером обновляется: меняется «Дата и время обновления», «Дата и время внесения» остаётся прежней.

### Когда сертификат помечается пропавшим

Только если место, где он был, **входило в это сканирование**: та же папка просматривалась, файлы такого типа искались, хранилища или контейнеры проверялись. Если в этот раз папку не смотрели, отметка не ставится. Если сертификат снова найден, отметка снимается.

## Файлы .p12 и .pfx

Такие файлы содержат закрытый ключ и обычно закрыты паролем. Без пароля программа их не открывает. В «Предупреждениях» появится «Файл PKCS#12 защищён паролем», а сертификат возьмётся из `.cer`, если он лежит рядом.

Чтобы читать `.p12`, добавьте пароль: **«Настройки» → «Пароли для .p12/.pfx…»**. Можно задать несколько паролей, программа пробует их по очереди. Пароли хранятся зашифрованными (DPAPI текущего пользователя Windows) и агентам не передаются. Поэтому `.p12` с паролем читаются при сканировании «Этот ПК» и без агента.

> Пароль к тестовым `.p12` из `samples/curator` — `changeit`.

## Настройки

Изменения применяются кнопкой **«Сохранить настройки»**. **«Отменить изменения»** возвращает сохранённые значения.

| Группа | Параметры |
|---|---|
| **База данных** | Сервер MSSQL (выпадающий список подставляет найденные на этом ПК экземпляры), имя БД, проверка подлинности Windows или логин и пароль SQL, таблица, «Создавать БД, если её нет», «Записывать результаты сразу». Кнопка **«Проверить подключение»** |
| **Агенты** | Порт (50555), общий ключ (**«Показать»**, **«Сгенерировать новый»**), таймаут ответа, сколько ПК сканировать параллельно, передавать ли агентам папки из панели, «искать только в этих папках», папка установки агента |
| **Журнал** | Папка журналов, срок хранения (сутки), максимальный размер файла (МБ) |
| **Сканирование** | Папки для поиска, расширения файлов, максимальный размер файла, хранилища «Личное», контейнеры КриптоПро, пароли для `.p12/.pfx` |

После смены общего ключа обновите агенты: выделите ПК → **«Агент на ПК» → «Установить / обновить агент на выбранных ПК»**. Иначе агенты будут отклонять запросы с новым ключом.

## Журнал

Вкладка «Журнал» показывает записи панели по мере появления. Файлы журнала лежат в папке `logs` рядом с программой: новый файл каждые сутки и при превышении размера, старые удаляются автоматически. Кнопки: **«Открыть папку журналов»**, **«Открыть файл журнала»**, **«Очистить окно»** (файл при этом не меняется).

Формат строки — как в задании, с точностью до миллисекунд и с уровнем записи:

```
14.11.26 14:15:52.590 - [INFO] Начато сканирование ПК: 1, способ: Local, параллельно: 8
14.11.26 14:15:52.630 - [WARN] Не удалось разобрать файл C:\Certs\broken.cer: CryptographicException: Требуемый объект не найден.
```

Все исключения, в том числе необработанные, пишутся в журнал со стеком.

## Сканирование по расписанию

`SkziControlPanel.exe --scan-all` сканирует все ПК из конфигурации без окна и записывает результат в БД. Задание должно выполняться с наивысшими правами (`/rl highest`): без прав администратора панель не запускается. Пример — ежедневно в 09:00, от имени текущего пользователя:

```bat
schtasks /create /tn "СКЗИ - сканирование сети" /sc daily /st 09:00 /rl highest ^
  /tr "\"%LOCALAPPDATA%\Programs\SkziControlPanel\SkziControlPanel.exe\" --scan-all"
```

Задание должно выполняться от той же учётной записи, под которой настроена панель: пароли в конфигурации расшифровываются только ею.

## Частые ситуации

| Что видно | Что сделать |
|---|---|
| ПК «нет ответа» | Агент не установлен или не запущен, порт 50555 закрыт. **«Агент на ПК» → «Проверить связь»**; на самом ПК — `SkziAgent.exe --status` |
| «Неверный ключ» | Ключ в панели и в `agent.config.xml` на ПК отличается. Обновите агент из панели |
| «Нет подключения к БД» | «Настройки» → «Проверить подключение». Проверьте имя сервера (`localhost\SQLEXPRESS`, `(localdb)\MSSQLLocalDB`) и права |
| Без агента: «Отказано в доступе» | Нужны права администратора на ПК и запущенная служба «Удалённый реестр» |
| В предупреждениях «защищён паролем» | Добавьте пароль в «Пароли для .p12/.pfx» |
| Сертификата нет, хотя файл есть | Проверьте, что папка в списке «Папки для поиска», а расширение — в списке расширений |
